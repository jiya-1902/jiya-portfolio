JIYA PRAJAPATI - DEVELOPER PORTFOLIO

FILES
- index.html : page structure and resume-based content
- style.css  : dark responsive design and layout
- script.js  : mobile navigation and current footer year

HOW TO RUN
1. Extract this ZIP file.
2. Open the extracted folder in Visual Studio Code.
3. Install the "Live Server" extension by Ritwick Dey if it is not already installed.
4. Right-click index.html and choose "Open with Live Server".

BEFORE PUBLISHING
- Check every statement, project detail, date and technology.
- The resume lists overlapping date ranges for Software Developer and Business Development Manager. Confirm these dates and explain the arrangement accurately before publishing.
- Confirm you are allowed to publicly describe each company project.
- Do not upload employer source code, confidential screenshots, customer information or internal data.
- Confirm that the public Knot-HR URL and LinkedIn URL are correct.
- This starter portfolio intentionally does not publish your phone number.
- The contact section uses a mailto link; it does not store messages in a database.
